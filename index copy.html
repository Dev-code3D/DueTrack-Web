Votre espace, vos choix

Local par défaut.
En ligne seulement si vous le décidez.

DueTrack ne nécessite pas de compte pour commencer. Une synchronisation Supabase personnelle peut être configurée volontairement. Des sauvegardes Google Drive ou GitHub privé pourront être activées séparément lorsqu’elles sont disponibles dans la version utilisée.

Chaque service en ligne implique un transfert de données : l’application doit vous l’expliquer avant toute activation.

Transparence

La confidentialité ne devrait pas être une option cachée.

Nous expliquons quelles données restent sur l’appareil, lesquelles peuvent être envoyées à un service choisi par l’utilisateur et comment les supprimer.

Questions fréquentes

Les réponses essentielles.

Dois-je créer un compte ?

Non. Le profil local est le mode de départ. Un compte ou un service distant est facultatif.

DueTrack lit-il mes comptes bancaires ?

Non. L’application ne se connecte pas automatiquement à votre banque et ne collecte pas vos identifiants bancaires.

Mes données sont-elles publiques sur GitHub Pages ?

Non, une page GitHub Pages héberge le code Web, pas les données locales du navigateur. Ne publiez jamais un export utilisateur ou un secret dans le dépôt.

Comment demander de l’aide ?

Ouvrez une issue non sensible sur le dépôt public. Ne partagez jamais de clé, token, mot de passe ou export personnel dans une issue.
