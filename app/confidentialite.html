📜 Introduction

Bienvenue sur DueTrack, une application conçue pour vous aider à suivre vos prêts et dettes entre proches de manière simple et sécurisée. chez OctopiDev, nous prenons la protection de vos données très au sérieux.

Cette politique de confidentialité explique comment nous collectons, utilisons, divisuons et protégeons vos informations.

🔒 Nos Principes Fondamentaux

Nous ne collectons PAS vos données personnelles.

DueTrack est conçue selon la philosophie "User First - Local First - Privacy First".

Nos engagements :

  • Local First : Toutes vos données sont stockées localement sur votre appareil par défaut.
  • Pas de collecte de données : OctopiDev ne collecte, ne stocke et ne vend AUCUNE de vos données.
  • Chiffrement : Vos exports de données sont chiffrés pour une protection maximale.
  • Transparence : Vous savez toujours où vos données sont stockées.
  • Contrôle total : Vous pouvez supprimer toutes vos données à tout moment.

📊 Quelles données sont impliquées ?

1. Données que VOUS créez :

  • Transactions : Noms, montants, dates, descriptions, statuts.
  • Profils : Noms des profils que vous créez.
  • Préférences : Thème, langue, devise, paramètres d'affichage.

2. Données d'authentification (si vous choisissez de vous connecter) :

  • Email : Votre adresse email (uniquement si vous utilisez l'authentification Google).
  • ID utilisateur : Identifiant unique généré par le fournisseur d'authentification.
  • Token d'authentification : Jetons sécurisés pour maintenir votre session.

⚠️ Important : Ces données d'authentification ne sont PAS stockées par OctopiDev. Elles sont gérées par :

  • Google : Si vous utilisez la connexion Google, vos informations sont gérées par Google selon leur politique de confidentialité.
  • Supabase : Si vous configurez un backend Supabase personnel, vos données sont stockées sur VOS serveurs Supabase, pas les nôtres.

💾 Où vos données sont-elles stockées ?

1. Stockage Local (par défaut) :

  • Toutes vos données sont stockées localement sur votre appareil.
  • Utilisation de Hive, une base de données locale sécurisée.
  • Les données ne quittent JAMAIS votre appareil sans votre consentement explicite.
  • Fonctionne à 100% sans connexion Internet.

2. Synchronisation Cloud (optionnelle) :

  • Supabase Personnel : Si vous configurez votre propre backend Supabase, vos données peuvent être synchronisées avec VOS serveurs.
    • Vous devez vous-même créer et configurer le projet Supabase.
    • OctopiDev n'a AUCUN accès à vos serveurs Supabase.
    • Vous contrôlez complètement vos données.
  • Google Drive Backup : Vous pouvez sauvegarder vos données dans votre Google Drive.
    • Les sauvegardes sont stockées dans un dossier duetrack_backup.
    • Les fichiers sont chiffrés avec un mot de passe que VOUS choisissez.
    • Seul vous pouvez accéder à ces sauvegardes.

3. Export de Données :

  • Vous pouvez exporter vos données en fichier JSON.
  • Les exports peuvent être chiffrés avec un mot de passe.
  • Vous êtes responsable de la sécurisation de ces fichiers exportés.
  • Ces fichiers sont stockés uniquement sur vos appareils.

🚫 Ce que nous NE faisons PAS

OctopiDev et l'application DueTrack ne font PAS :

  • Collecter vos données personnelles ou de transaction.
  • Vendre vos données à des tiers.
  • Analyser vos données pour du marketing ou de la publicité.
  • Partager vos données avec qui que ce soit sans votre consentement.
  • Accéder à vos données stockées sur votre appareil ou vos services cloud personnels.
  • Stocker vos données sur nos serveurs (nous n'avons PAS de backend pour vos données).

🔄 Partage de Données (avec votre consentement)

Dans de rares cas, vous pourriez choisir de partager des informations avec nous :

1. Rapports de Bugs :

  • Si vous signalez un bug, vous pourriez nous fournir :
    • Des captures d'écran (sans données personnelles).
    • Les étapes pour reproduire le bug.
    • Les logs d'erreur (sans données sensibles).
  • Ces informations sont utilisées uniquement pour résoudre le problème.

2. Suggestions de Fonctionnalités :

  • Vous pouvez nous envoyer des suggestions pour améliorer l'application.
  • Ces suggestions ne contiennent aucune de vos données personnelles.

3. Donations :

  • Si vous choisissez de soutenir le développement via Liberapay,
  • les informations de paiement sont gérées par Liberapay selon leur politique.

🗝️ Sécurité de vos Données

Mesures de Protection :

  • Stockage Local Sécurisé : Utilisation de Hive, une base de données chiffrée.
  • Chiffrement des Exports : AES-256 pour les sauvegardes chiffrées.
  • Authentification Sécurisée : OAuth 2.0 avec Google.
  • Row Level Security (RLS) : Sur Supabase, chaque utilisateur ne peut accéder qu'à SES propres données.
  • Pas de clé service_role : Notre application n'utilise JAMAIS de clé administrative.

Vos Responsabilités :

  • Protéger votre appareil avec un code PIN/mot de passe.
  • Ne pas partager votre appareil avec des personnes non fiables.
  • Sauvegarder régulièrement vos données (export ou Google Drive).
  • Choisir un mot de passe fort pour les exports chiffrés.
  • Garder votre clé Supabase secrète si vous en configurez une.

🗑️ Suppression de vos Données

Vous avez le contrôle total sur vos données. Voici comment les supprimer :

1. Supprimer les Données Locales :

  1. Ouvrez l'application DueTrack.
  2. Allez dans Paramètres → Supprimer les données locales.
  3. Confirmez 3 fois pour supprimer toutes vos données locales.

2. Supprimer les Données Cloud (Supabase) :

  1. Ouvrez l'application DueTrack.
  2. Allez dans Paramètres → Supprimer les données cloud.
  3. Confirmez pour supprimer toutes vos données de votre backend Supabase.

3. Supprimer votre Compte Supabase :

  1. Ouvrez l'application DueTrack.
  2. Allez dans Paramètres → Supprimer mon compte.
  3. Confirmez pour supprimer votre compte utilisateur et toutes vos données associées.
  4. Note : Cela ne supprime que les données de VOTRE projet Supabase, pas l'application elle-même.

4. Supprimer les Sauvegardes Google Drive :

  1. Ouvrez Google Drive.
  2. Cherchez le dossier duetrack_backup.
  3. Supprimez manuellement le dossier et son contenu.

5. Désinstaller l'Application :

  1. Désinstallez l'application depuis votre appareil.
  2. Note : Vos données locales seront également supprimées.
